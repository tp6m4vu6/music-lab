和聲學習索引

基礎

和弦與功能

三和弦／七和弦、調內和弦、級數、主屬功能、轉位與 Voice Leading。

例如：Em → C → G → D，可先確認每個和弦組成音，再比較聲部之間的最近移動。
進階

和聲色彩

次屬和弦、Modal Interchange、add9、sus4、延伸和弦與轉調。

例如：在 A 大調中 F♯7 → Bm 是 V7/ii → ii，注意 A♯ → B 的導向。

音色製作教學

從 K-pop Lead、Funk Bass 到 Warm Keys，一步步在 Vital 重做音色。

建議順序：先聽目標音色 → OSC → Envelope / Filter → LFO → FX。需要查看影片中 Serum 控制項的位置時，請開啟「Serum → Vital 對照」內部分頁：

實作配方

從最常出現在 K-pop 和 Funk 的音色開始製作。

學習路線

1
OSC：先確定音色的骨架

波形、音高、Unison、Detune。FX 先全部關掉。

2
ENV + Filter：調整起音、明暗與長短

Attack、Decay、Sustain、Release 與 Cutoff，先還原「形狀」。

3
LFO + Matrix：模仿節奏和動態

把 LFO 指派到 Cutoff、Pitch、Volume 等，檢查 Trigger、Rate、調變深度。

4
FX：最後才比對整體質感

Chorus、Reverb、Delay、Distortion；同時比對音量以免被響度誤導。

RHYTHM & STYLES

節奏與曲風

把「切分」拆成可辨認、可套用的 Groove，不只依靠曲風名稱。

核心概念

元素FunkUK Garage
Groove 核心鼓、Bass、吉他／鍵盤間的鎖定與切分，重視 pocket常見帶 Swing 的切分與 2-step 鼓組組織
鼓組常以清楚的 Backbeat 與細節 Ghost Notes 支撐Kick、Snare 分布更不規則，Hi-hat / Shaker 常帶 Shuffle
Bass常和鼓形成問答、重音互補可出現彈性、滑動與具律動感的合成 Bass
注意不是每個樂器都要一直切分；空隙也很重要不能只靠是否有切分判定；看鼓型、律動和整體編曲

MIXING

混音與音色

先掌握決定清晰度與質感的核心處理，不必一開始就追求複雜母帶。

Sidechain 的 2–4 dB Gain Reduction 只是常見練習起點，不是每首歌都需要達到的目標；要以節奏、聲音密度與聽感決定。
